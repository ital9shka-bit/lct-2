# Исходный дизайн интерфейса

В экспертной поставке сохранены два файла действующего HTML-дизайна: `template.html` и `assessment.css`. Интерфейс продолжает предоставленный дизайн v12 и редакцию v13.

Сборка `implementation/tools/build.mjs` берёт этот шаблон, сохраняет визуальные токены и объединяет его с действующими модулями `implementation/client/`. Статические демонстрационные заглушки заменяются данными API.

Отдельный старый браузерный прототип, его сборки, скриншоты ревью и зависимости не включены. Запускайте приложение из [корневой инструкции](../README.md). Не открывайте шаблон как самостоятельное действующее приложение.
