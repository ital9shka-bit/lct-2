# Исходное ТЗ ООП — версия 0.8

Зафиксированный комплект от 8 октября 2026 года. Основное название: **Объекто-ориентированный поиск**. Эта папка сохраняет текст требований и приложения исходной постановки. Она не является отчётом о текущей готовности реализации.

| Документ | Содержание |
| --- | --- |
| [01 — ТЗ](01_development_specification.md) | Роли, состояния, данные, оценка, права и требования |
| [02 — профессиональный банк](02_professional_bank.md) | Исходные вопросы Backend Junior/Middle, эталоны и рубрики |
| [03 — когнитивный блок и самооценка](03_cognitive_and_self.md) | Исходные формы и вопросы |
| [04 — приёмочные сценарии](04_qa_test_cases.md) | 87 плановых случаев; также JSON/CSV |
| [05 — OpenAPI](05_api.openapi.json) | Исходный контракт версии 0.8 |
| [06 — приёмка UI](06_ui_acceptance.md) | Переходы и состояния исходного интерфейса |
| [07 — план и трассировка](07_work_plan_and_traceability.md) | Исходные этапы и оценка работ |
| [08 — валидация](08_validation_protocol.md) | Условия независимого ревью, пилота и автофинализации |

Действующие дополнения: [продукт](../../docs/product.md), [методика](../../docs/assessment.md), [API](../../docs/api.md). Порядок блоков, расширенные специализации, опыт, SSO и ИИ описаны там. Исходные формулы технического подтверждения и подбора сохранены.

Старые упоминания планируемого backend, порядка блоков, сроков, локальных заглушек и не подключённых сервисов относятся к моменту подготовки ТЗ. Статус текущей реализации подтверждается [проверками](../../docs/testing.md), а не исходными плановыми пометками.

JSON с суффиксом `.private.json` содержит ключи ответов для экспертов и серверной разработки; в клиентский bundle не входит. Для публикации убраны дублирующий ZIP/Word, промежуточные отчёты, кэши и старые генераторы документов. Нормативные Markdown, JSON и CSV сохранены.
