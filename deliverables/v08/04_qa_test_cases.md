# Проверочные сценарии ООП

Версияqa0.8.0. 87 сценариев для полной серверной и UI реализации. Все backend сценарии имеют статус planned_for_backend. Выполненные проверки локального прототипа и их доказательства приведены отдельно; они не заменяют эти сценарии.

Имена, контакты и события в сценариях synthetic. Серверные часы и модели можно подменять адаптерами test окружения. Каждая проверка исполняется с чистыми исходными данными либо явно созданной историей.
