# Объекто-ориентированный поиск

Название продукта: **Объекто-ориентированный поиск**, сокращение **ООП**. В интерфейсе пользователь соискатель называется «талант»; внутренние API используют совместимое имя роли `candidate`.

Действующий интерфейс собирается из `prototype-v13/template.html`, `prototype-v13/assessment.css` и `implementation/client`. Не править сгенерированный `implementation/public`.

ТЗ `deliverables/v08` — зафиксированная исходная спецификация. Действующие дополнения и границы демо описаны в `docs/assessment.md` и `docs/product.md`. Не менять формулы профессиональной оценки и подбора без явного продуктового решения. Каждый блок оценки можно отложить. Когнитивные наблюдения и самооценка не повышают технический грейд.

Секреты, `.env`, экспорт БД и сгенерированный realm Keycloak не коммитить. Все демонстрационные данные вымышленные. Проверять изменение через `bash scripts/verify.sh`; сценарий создаёт и удаляет только собственный тестовый Compose-проект. Интеграционные тесты нельзя запускать на базе действующего стенда.
